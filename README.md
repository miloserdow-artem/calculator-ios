# Сalculator-ios

Учебный проект — калькулятор с дизайном в стиле iOS.

Это один из моих первых учебных проектов. Он помог мне разобраться с основами адаптивной вёрстки, работой с UI‑элементами и логикой вычислений.

**Дата создания:** 2 марта 2022 года

## Функционал
- **Базовые арифметические операции:** Сложение (`+`), вычитание (`-`), умножение (`×`), деление (`÷`).
- **Поддержка десятичных чисел:** Работа с дробной частью.
- **Управление вводом:** Кнопка полной очистки (`AC`) и удаления последнего символа.
- **Адаптивный интерфейс:** Вёрстка полностью адаптирована под экраны iPhone.

## Технологии
- Чистый JavaScript (Vanilla JS)
- HTML5
- CSS3 (Flexbox/Grid для адаптивности)
