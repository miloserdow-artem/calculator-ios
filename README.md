# calculator-ios
Учебный проект — калькулятор с дизайном в стиле iOS.

Это один из моих первых учебных проектов — помог разобраться с основами разработки под iOS, работой с UI‑элементами и логикой вычислений.
Дата создания 2 марта 2022 года

## Функционал
1. Базовые арифметические операции: +, -, ×, ÷;
2. Поддержка десятичных чисел;
3. Кнопка очистки и удаления последнего символа;
4. Адаптивный интерфейс под экраны iPhone.
## Технологии
- Чистый JavaScript
