# calculator-ios

A training project — a calculator featuring an iOS-style design.

This is one of my very first educational projects. It helped me understand the fundamentals of responsive layout, UI elements management, and calculation logic.

**Creation Date:** March 2, 2022

## Features
- **Basic arithmetic operations:** Addition (`+`), subtraction (`-`), multiplication (`×`), division (`÷`).
- **Decimal support:** Handles calculations with fractional numbers.
- **Input control:** Features a clear button (`AC`) and a backspace functionality to delete the last character.
- **Responsive interface:** The layout is fully optimized to fit iPhone screens.

## Tech Stack
- Vanilla JavaScript
- HTML5
- CSS3 (Flexbox/Grid for responsiveness)
