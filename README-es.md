# calculator-ios

Proyecto de aprendizaje: una calculadora con diseño al estilo iOS.

Este es uno de mis primeros proyectos educativos. Me ayudó a comprender los fundamentos del diseño adaptitativo, el manejo de elementos de la interfaz de usuario (UI) y la lógica de los cálculos matemáticos.

**Fecha de creación:** 2 de marzo de 2022

## Características
- **Operaciones aritméticas básicas:** Suma (`+`), resta (`-`), multiplicación (`×`), división (`÷`).
- **Soporte de números decimales:** Permite realizar cálculos con fracciones.
- **Control de entrada:** Botón de limpieza total (`AC`) y función para borrar el último carácter introducido.
- **Interfaz adaptable:** El diseño está completamente optimizado para las pantallas de iPhone.

## Tecnologías
- JavaScript puro (Vanilla JS)
- HTML5
- CSS3 (Flexbox/Grid para la adaptabilidad)
